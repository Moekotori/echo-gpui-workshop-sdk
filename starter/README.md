# Your first ECHO plugin

Use an installed ECHO GPUI build and a text editor. The sample runs as JavaScript directly
in ECHO. Rust, Cargo, npm, and a build step are unnecessary for this project.

1. Open **Plugins → Create → Run development package** and select
   `echo.workshop.json`. In a project generated by ECHO, look in `content/`.
2. Edit `plugin.mjs` beside the manifest and save. ECHO reloads your plugin and shows the updated page.
   Open the session log to see messages from `console` and any errors.
3. Edit the title, ID, and version in the manifest before sharing. Keep the ID for future updates.
   To upload to Steam, open **Plugins → Create → Choose project folder**. Add a preview when prompted and confirm visibility. For later releases, select the same project and choose **Update content**.
   To share a ZIP from a project generated by ECHO, run `echo-gpui --workshop pack my-plugin-release.zip`.
   For the downloaded starter, run `echo-gpui --workshop pack starter my-plugin-release.zip` from its parent folder.
   The recipient can drop the ZIP into Plugins or choose **Installed → Install or import file**.

From this folder, run `echo-gpui --workshop check` to validate the manifest,
`echo-gpui --workshop test` to run your plugin with a temporary library, or
`echo-gpui --workshop dev` to rerun that check each time you save a file in the package.
Run `echo-gpui --workshop test . now-playing` to print the result of the starter's registered command.

The bundled `echo-workshop.d.ts` gives TypeScript-aware editors completions in the JavaScript
source. A TypeScript project can compile to an `.mjs` entry and point `gpui.entry` to it.
See the [public SDK](https://github.com/Moekotori/echo-gpui-workshop-sdk) for the API, additional examples and publishing steps.

# 你的第一个 ECHO 插件

准备已安装的 ECHO GPUI 和文本编辑器即可。示例是直接运行的 JavaScript，无需 Rust、Cargo、
npm 或编译步骤。

1. 在 **插件 → 创作 → 临时运行开发包** 选择 `echo.workshop.json`。应用生成的项目中，清单位于 `content/`。
2. 编辑并保存清单旁的 `plugin.mjs`，ECHO 会重载插件。用「查看日志」检查输出与报错。
3. 分享前在清单里设置名称、标识和版本，更新时沿用标识。连接 Steam 后，在「插件 → 创作 → 选择项目文件夹」选中项目，按提示选择预览图并确认可见范围。下次选同一项目，点「更新内容」即可。
   如需单独分发 ZIP，在应用生成的项目里运行
   `echo-gpui --workshop pack my-plugin-release.zip`。从 SDK 下载的示例可在 `starter` 的上一级运行
   `echo-gpui --workshop pack starter my-plugin-release.zip`。收件人可以把 ZIP 直接拖进插件页，
   或在「已安装 → 安装 / 导入文件」选择 ZIP。

在项目目录运行 `echo-gpui --workshop check` 校验清单，运行 `echo-gpui --workshop test`
用临时曲库启动插件，或运行 `echo-gpui --workshop dev` 在每次保存包目录内的文件后重跑验证。
用 `echo-gpui --workshop test . now-playing` 可直接运行示例注册的命令并查看 JSON 结果。

随附的 `echo-workshop.d.ts` 为支持 TypeScript 的编辑器提供 JavaScript 补全。使用 TypeScript
开发时，在清单里用 `gpui.entry` 指定编译后的 `.mjs` 入口。接口、进阶示例和发布步骤见
[公开 SDK](https://github.com/Moekotori/echo-gpui-workshop-sdk)。
